How to split a PDF

  1. Add a PDF by dragging it onto the box or clicking to browse.
  2. Pick a mode: extract a page range, split every N pages, or split each page into its own file.
  3. Enter the pages or chunk size, then select Split PDF.
  4. Download a single PDF or, when several files are produced, a ZIP archive.

Need the reverse? Try Merge PDF to combine documents back together.

Frequently asked questions

How do I extract specific pages from a PDF?

Choose Extract page range and type pages and ranges such as 1-3, 5, 8-10. ConvertKit creates a new PDF containing exactly those pages, in the order you list them.

Can I split every page into its own file?

Yes. Select Split each page. Each page becomes a separate PDF and the results are delivered together in a ZIP file.

Is my PDF uploaded anywhere?

No. The file is read and rebuilt inside your browser. You can confirm in the Network tab that no document data is transmitted.
