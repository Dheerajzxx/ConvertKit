How to merge PDFs

  1. Drop two or more PDF files onto the box above, or click to browse. You can also paste files with Ctrl + V.
  2. Drag the file cards — or use the arrow buttons — so the pages appear in the order you want.
  3. Select Merge PDFs. The combined PDF is built locally and a download button appears.
  4. Download the result, then use Convert another to start over.

Everything happens on your device. The files are read with the browser's File API, combined with an in-browser PDF library, and saved back to your downloads folder. No network request carries your document.

Frequently asked questions

Are my PDF files uploaded to a server?

No. The merge runs inside your browser tab. You can verify this in your browser's Network tab — no document data is sent anywhere.

Can I change the order of the PDFs?

Yes. Drag the cards to reorder them, or use the up and down buttons on each card. The merged document follows the list order from top to bottom.

Why does a password-protected PDF fail?

Encrypted PDFs cannot be read without the password. Remove the password in a PDF viewer first, then add the file again.

Is there a file size limit?

Each PDF can be up to 200 MB. Very large merges depend on your device's memory — close other heavy tabs if a merge fails, then try again with fewer files.
