Frequently asked questions

        

          

            What JSON shapes are supported?
            
An array of objects is ideal. A single object becomes one row. If your array lives under a key such as data or items, it is found automatically.

          

          

            How are nested objects handled?
            
With flattening enabled, nested keys become dot-notation columns such as address.city. Arrays are stored as JSON text in a single cell.

          

          

            Is my JSON uploaded?
            
No. Parsing and conversion happen entirely inside your browser, so no data is transmitted.
