Frequently asked questions

        

          

            How are rows shaped into JSON?
            
With a header row, each row becomes an object using the column names as keys. Without one, keys are column_1, column_2, and so on.

          

          

            Can it handle quotes and commas inside values?
            
Yes. The parser understands quoted fields, escaped quotes, embedded commas and even line breaks inside quotes — the usual CSV edge cases.

          

          

            Is my data uploaded?
            
No. Everything runs in your browser tab and no data is sent to a server. You can confirm it in the Network tab.
