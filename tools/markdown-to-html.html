Frequently asked questions

        

          

            Which Markdown features are supported?
            
GitHub-flavoured Markdown: headings, emphasis, links, images, lists, tables, blockquotes, inline code and fenced code blocks.

          

          

            Is the HTML safe to paste into my site?
            
Yes, it is sanitised and strips scripts and event handlers. Still follow your platform's own content rules when publishing.

          

          

            Does this work offline?
            
Once the page has loaded, yes. Everything runs locally with no network calls, so it keeps working without a connection.
