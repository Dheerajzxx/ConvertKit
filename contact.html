Contact

Feedback, bug reports and tool ideas are all welcome.

Bugs and feature requests

The fastest way to reach the project is the public issue tracker. Search first to see if your item already exists, then open a new issue with a clear description and, if possible, a sample file.

Open the issue tracker

Everything else

For general questions about the project, open a discussion in the repository. Please do not attach confidential documents — never share real personal or financial files in a public issue.

Start a discussion

ConvertKit has no contact form and no email list — keeping it that way means there is no database of messages to protect. Public issues and discussions keep everything transparent.
