Privacy policy

The short version: your files never leave your device. This page explains exactly what that means.

No file you open here is ever uploaded, stored, logged, shared or analysed. There is no server that receives your documents.

Files you open

When you drop a file onto a tool page, it is read by JavaScript running in your own browser tab. Conversion, compression, merging and every other operation happens on your device. The finished file is saved directly to your downloads folder.

You can verify this yourself: open your browser's developer tools, switch to the Network tab, and run a conversion. You will not see any request carrying your file's contents.

What is stored on your device

ConvertKit uses localStorage for two small, optional things, both kept only in your browser:

  • Theme choice — whether you prefer the light or dark interface.
  • Recently used tools — a short list of tool names so the home page can show shortcuts. No file data is stored, ever.

You can clear both at any time by clearing your browser's site data. If storage is unavailable, the tools still work.

Analytics and cookies

This version of ConvertKit sets no cookies and runs no analytics or advertising scripts. If privacy-friendly analytics are added later, this page will be updated first, and any such tool would only ever receive anonymous page views — never file names or contents.

Third-party libraries

The conversion libraries are bundled with the site and served from the same origin, so using a tool does not contact any other domain. Their names and licences are listed in THIRD_PARTY_LICENSES.md.

Links to other sites

Some pages may link to external resources, such as a library's homepage or the project repository. Once you follow such a link, that site's own privacy policy applies.

Children's privacy

ConvertKit does not collect personal information from anyone, including children, because it does not collect personal information at all.

Changes to this policy

If this policy changes, the update will appear on this page with a new date. Because there is no account or email list, there is nothing else to notify you through.
